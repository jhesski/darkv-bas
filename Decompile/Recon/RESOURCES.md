# DV1 Resource File Inventory

Generated by tools/inspect_resources.ps1. Documents the format of each resource file type in org/.

## Format summary

### .PIC files - uniform format

Binary BSAVE files. All are 16391 bytes = 7-byte header + 16384-byte payload. Header decodes to segment 0xB800, offset 0x0000, length 0x4000. These are direct dumps of the CGA SCREEN 1 video page, loaded with `DEF SEG = &HB800: BLOAD "<name>.pic", 0`.

### .PAC files - multiple sub-formats

Text CSV but the structure varies by purpose:

| Sub-format | Files | Structure |
|-----------|-------|-----------|
| **Hit map** | ROOM1-11, DESK, OPENCLOS, RACK, SAFE, TABLE, WINDOW | `palette4tuple` header + `x,y,objID` rows + `0,0,0` padding to 100 entries. Clickable region map per scene. |
| **Blank hit map** | DEATH, DINDEAD, LIGHTN | Same header, all entries are `0,0,0`. Non-interactive cutscenes. |
| **Object descriptions** | OBJECT.PAC | `objID,"description"` pairs. 25+ inventory item LOOK descriptions. Equivalent to Dream-Giver `des$()`. |
| **Save game** | SAVERA-E.PAC | `"name",score,time,"","cursor1","cursor2","slot"` + flag list. Loaded by save/restore code. |
| **Embedded BASIC source** | ENDER.PAC | Literal QB4.5 source (`DEFINT`, `SCREEN`, `PALETTE`, `BLOAD`, `PLAY`, `SOUND`). The ending sequence, likely CHAINed or RUN at game end. |

### .PCT files - sprite data

Text CSV of integers from QB GET arrays. Width varies by sprite:

| File | Width | Subject |
|------|-------|---------|
| DOOR.PCT | 4 ints/row | Cursor or door sprite (large) |
| GOLF.PCT, JOED, JOES, JOEW1-4, WILB | 2 ints/row | Character sprites (Joe walking 1-4, dying, standing; Wilbur; golf club) |
