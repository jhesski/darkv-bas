## What each kind means

### Subroutine pseudo-label
Spring artifact. Marks where a SUB or labeled block begins in the original.
Reconstruction: mechanical - convert `Subroutine SNNNN` to a label `SNNNN:`. Most are inline labels, not SUB blocks (matches DV2/Dream-Giver style).

### Rem error 12
QB error 12 = Illegal function call. Spring placeholder for an instruction it could not decode.
Reconstruction: pattern-match neighboring code. Likely a PUT/GET/PALETTE/SOUND call. Recover from Dream-Giver patterns + EXE empirical check via DOSBox debugger.

### Rem error 17
QB error 17 = Subscript out of range. Spring placeholder for an array access it could not decode.
Reconstruction: reconstruct from surrounding loop context (the array and index are usually obvious from nearby code).

### ???? target / S???? target
Unresolved GOTO/GOSUB target. Spring could not match the branch destination to a known line.
Reconstruction: match to a known label by line-number proximity + control flow context.
